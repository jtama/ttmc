--- title: Java questions: - question: | Vrai ou Faux : Java et JavaScript sont deux langages complètement différents. answer: | ✅ **Vrai !** Malgré leurs noms, Java et JavaScript sont deux langages distincts. C'est un peu comme comparer une voiture et un tapis volant parce qu'ils permettent tous les deux de se déplacer. ☕ - question: | Vrai ou Faux : En Java, ce code permet de stocker le nombre `42` : ```java int level = 42; ``` answer: | ✅ **Vrai !** Le type `int` permet de stocker un nombre entier. Niveau 42 débloqué. 🎮 - question: | Vrai ou Faux : Ce code affiche `Hello Geek` : ```java String player = "Geek"; System.out.println("Hello " + player); ``` answer: | ✅ **Vrai !** L'opérateur `+` permet ici de concaténer les deux chaînes de caractères. 👾 - question: | Vrai ou Faux : Une variable déclarée `final` peut changer de valeur plus tard dans le programme. ```java final int maxLevel = 10; ``` answer: | ❌ **Faux !** Une variable `final` ne peut plus être réassignée après son initialisation. Le niveau maximum restera donc à 10. 🔒 - question: | Vrai ou Faux : Ce code affiche `5` : ```java int score = 10 / 2; System.out.println(score); ``` answer: | ✅ **Vrai !** Les deux opérandes sont des entiers et `10 / 2` donne bien `5`. Jusque-là, Java est encore gentil avec nous. 😇 - question: | Vrai ou Faux : Ce code affiche `2.5` : ```java int result = 5 / 2; System.out.println(result); ``` answer: | ❌ **Faux !** Il affiche `2`. Comme `5` et `2` sont des entiers, Java effectue une division entière et supprime la partie décimale. Et voilà le premier piège. 😈 - question: | Vrai ou Faux : En Java, une `String` peut être comparée de manière fiable avec `==` pour vérifier si deux chaînes contiennent le même texte. ```java String player1 = new String("Mario"); String player2 = new String("Mario"); System.out.println(player1 == player2); ``` answer: | ❌ **Faux !** `==` compare ici les références des objets. Pour comparer leur contenu, on utilise généralement `player1.equals(player2)`. 🍄 - question: | Vrai ou Faux : Une classe Java peut hériter directement de plusieurs classes en même temps. ```java class SuperHero extends Batman, Superman { } ``` answer: | ❌ **Faux !** Java n'autorise pas l'héritage multiple de classes. Une classe ne peut étendre directement qu'une seule classe. Même un super-héros doit respecter les règles. 🦸 - question: | Vrai ou Faux : Ce code compile correctement : ```java int[] levels = {1, 2, 3}; System.out.println(levels[3]); ``` answer: | ✅ **Vrai !** Le code peut compiler, mais son exécution provoquera une `ArrayIndexOutOfBoundsException`. Les indices disponibles sont `0`, `1` et `2`. Le niveau 3 était un piège. 💥 - question: | 👾 **BOSS FINAL — Vrai ou Faux :** Ce code affiche `true` : ```java Integer score1 = 100; Integer score2 = 100; System.out.println(score1 == score2); ``` answer: | ✅ **Vrai !** Java met généralement en cache les objets `Integer` correspondant aux valeurs de `-128` à `127`. ---

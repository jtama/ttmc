--- title: CSS questions: - question: | Vrai ou Faux : La pseudo-classe `:where()` a toujours une spécificité de `0`, même si elle contient un sélecteur très spécifique. ```css :where(#app .card button) { color: red; } ``` answer: | ✅ **Vrai !** `:where()` possède une spécificité nulle, quel que soit le sélecteur placé entre ses parenthèses. - question: | Vrai ou Faux : La pseudo-classe `:has()` permet de sélectionner un élément en fonction des éléments qu'il contient. ```css .card:has(img) { padding: 0; } ``` answer: | ✅ **Vrai !** Ici, seules les `.card` correspondant à la condition `:has(img)` sont sélectionnées. - question: | Vrai ou Faux : Avec ce code, `.child` peut forcément passer devant tous les autres éléments de la page grâce à son `z-index: 9999`. ```css .parent { position: relative; z-index: 1; } .child { position: absolute; z-index: 9999; } ``` answer: | ❌ **Faux !** Le `z-index` de l'enfant reste contraint par le contexte d'empilement de son parent. - question: | Vrai ou Faux : Appliquer `opacity: 0.99` à un élément peut créer un nouveau contexte d'empilement. answer: | ✅ **Vrai !** Une valeur d'`opacity` inférieure à `1` crée un nouveau stacking context. - question: | Vrai ou Faux : Avec CSS Grid, `minmax(0, 1fr)` peut être utile à la place de `1fr` pour permettre à une colonne de se réduire malgré un contenu volumineux. ```css .layout { display: grid; grid-template-columns: minmax(0, 1fr) 300px; } ``` answer: | ✅ **Vrai !** `minmax(0, 1fr)` autorise explicitement la piste à descendre jusqu'à `0`. - question: | Vrai ou Faux : Une `@container` query permet d'adapter un composant en fonction de la taille de son conteneur plutôt que de celle du viewport. ```css @container (width > 500px) { .card { display: grid; } } ``` answer: | ✅ **Vrai !** Les container queries permettent notamment de réagir aux dimensions d'un conteneur. - question: | Vrai ou Faux : `margin-inline-start` correspond obligatoirement à `margin-left`. answer: | ❌ **Faux !** Les propriétés logiques s'adaptent notamment au sens d'écriture du document. - question: | Vrai ou Faux : Dans des `@layer`, un sélecteur extrêmement spécifique placé dans une couche moins prioritaire peut perdre face à un simple sélecteur placé dans une couche plus prioritaire. ```css @layer base, components; @layer base { #app .page .card button { color: blue; } } @layer components { button { color: red; } } ``` answer: | ✅ **Vrai !** La priorité des couches est évaluée avant la spécificité des sélecteurs appartenant à ces couches. - question: | Vrai ou Faux : `display: contents` fait disparaître l'élément du DOM et déplace réellement ses enfants dans son parent. answer: | ❌ **Faux !** `display: contents` affecte la génération de boîtes CSS, mais ne déplace pas les éléments dans le DOM. - question: | 👾 **BOSS FINAL — Vrai ou Faux :** Ajouter `transform: translateZ(0)` sur un élément peut modifier le comportement de ses descendants utilisant `z-index`, même si l'élément ne semble pas avoir bougé visuellement. ```css .container { transform: translateZ(0); } ``` answer: | ✅ **Vrai !** Une transformation différente de `none` crée un nouveau contexte d'empilement et peut donc modifier le comportement des `z-index`. ---

--- title: JavaScript questions: - question: | Vrai ou Faux : JavaScript peut changer le texte d'un bouton **sans recharger toute la page**. answer: | ✅ **Vrai !** JavaScript peut modifier directement le DOM. Heureusement, sinon chaque clic serait une aventure. 😅 - question: | Vrai ou Faux : Ce code affiche `Hello Batman` : ```javascript const hero = "Batman"; console.log(`Hello ${hero}`); ``` answer: | ✅ **Vrai !** Les template literals avec les backticks permettent d'insérer une variable avec `${...}`. 🦇 - question: | Vrai ou Faux : En JavaScript, ceci est parfaitement possible : ```javascript const sac = ["PC", 42, true, "café ☕"]; ``` answer: | ✅ **Vrai !** Un tableau JavaScript peut contenir plusieurs types de valeurs. Même du café, et c'est probablement le plus important. ☕ - question: | Vrai ou Faux : Après ce code, Batman a disparu du tableau : ```javascript const heroes = ["Batman", "Spider-Man", "Deadpool"]; heroes.shift(); ``` answer: | ✅ **Vrai !** `shift()` retire le premier élément du tableau. Batman est donc parti bouder dans sa Batcave. 🦇 - question: | Vrai ou Faux : Ce code affiche `55` : ```javascript console.log("5" + 5); ``` answer: | ✅ **Vrai !** Comme l'une des valeurs est une chaîne de caractères, JavaScript effectue une concaténation et affiche `"55"`. - question: | Vrai ou Faux : Ce code affiche `true` : ```javascript console.log(0 == false); ``` answer: | ✅ **Vrai !** Avec `==`, JavaScript effectue une conversion implicite des types. Avec `0 === false`, le résultat serait `false`. JavaScript commence à jouer avec nos nerfs. 😈 - question: | Vrai ou Faux : Ce code provoque une erreur : ```javascript const snacks = ["🍕", "🍔"]; snacks.push("🍪"); ``` answer: | ❌ **Faux !** Même déclaré avec `const`, le contenu d'un tableau peut être modifié. On ne peut simplement pas réassigner `snacks` à un autre tableau. Le cookie est sauvé. 🍪 - question: | Vrai ou Faux : En JavaScript, `typeof null` retourne `"null"`. answer: | ❌ **Faux !** Il retourne `"object"`. C'est une particularité historique de JavaScript. Oui, même JavaScript traîne encore des casseroles des années 90. 📼 - question: | Vrai ou Faux : Ce code affiche `false` : ```javascript console.log(NaN === NaN); ``` answer: | ✅ **Vrai !** L'expression affiche bien `false`. `NaN` n'est pas égal à lui-même. Pour le détecter proprement, on peut utiliser `Number.isNaN()`. - question: | 👾 **BOSS FINAL — Vrai ou Faux :** Ce code affiche `1`, puis `2`, puis `3`. ```javascript console.log(1); setTimeout(() => { console.log(2); }, 0); console.log(3); ``` answer: | ❌ **Faux !** Il affiche `1`, puis `3`, puis `2`. ---
